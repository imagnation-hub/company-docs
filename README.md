# 楚邦上易 · 企业资料中心

在线浏览公司介绍 PDF，扫码即看，实时更新。

## 文件说明

- `index.html` — 资料列表主页（含子二维码）
- `viewer.html` — PDF 在线阅读器
- `pdfs/` — PDF 文件存放目录
- `qrcodes/` — 二维码图片
- `img/` — 图片资源

## 更新 PDF 的方法

1. 打开 GitHub → 进入此仓库 → `pdfs/` 文件夹
2. 删除旧 PDF，上传**同名**新 PDF
3. 等待 1 分钟生效

二维码永久不变，无需重新打印。

## 添加新 PDF 的方法

1. 上传 PDF 到 `pdfs/` 文件夹
2. 编辑 `index.html`，在 `files` 数组中添加新条目
3. 保存后自动生效
